## 运行

```powershell
.\venv\Scripts\python.exe -m pip install -r requirements-dev.txt
.\venv\Scripts\python.exe evals\run_formal_evaluation.py
.\venv\Scripts\python.exe evals\run_eval.py
```

脚本自动建立临时 SQLite，关闭 LLM、联网搜索和语义模型下载，不使用生产连接串。全量模板冻结时刻为 `2026-10-03T10:00:00+08:00`，原始赛事日期不平移。失败返回非零退出码。

## 断言与口径

- 同年同名多赛道必须追问；指定完整名称先于“数学建模”等主题猜测。
- 已有目标字段原文的事实问句才进入引用召回分母；缺失原文另计安全拒答。
- 引用比较原文、页码、来源链接、获取/检查日期、文档指纹及锚点，不能靠结构化摘要制造引用。
- 未核验或缺证据时禁止评分和资格结论；已截止赛事不生成新的招募文案。
- 正式推荐允许为空；非空结果必须满足统一来源、时间与画像门控。
- `gate_consistency` 比较同源实现，只是内部一致性，不是独立现实资格准确率。
- 输出逐条答案、引用、断言、失败原因及各指标真实分母；异常计为整条失败。

## 文件

- `formal_results.json` 与 [正式报告](../docs/QUANTITATIVE_EVALUATION.md)。
- `metrics.json` 包含全部模板逐条结果；[模板报告](report.md) 汇总适用分母与失败明细。
- 两组结果记录数据文件、源码/测试代码和赛事快照 SHA-256；质量驾驶舱发现源码或数据库变化后标记需复测，不将历史数字当作当前成绩。
