# 测试用例摘要

完整自动化回归共 152 项（另有 26 项子测试）；下表选取 15 项，覆盖正常、异常、边界和安全场景，满足不少于 10 条的提交要求。

| ID | 场景 | 类型 | 预期结果 |
| --- | --- | --- | --- |
| TC-01 | Ground Truth 与数据库日期比对 | 正常 | 196 条赛事报名/提交日期一致 |
| TC-02 | 已截止赛事推荐 | 边界 | 返回 `ineligible`，不计算分数 |
| TC-03 | 基础资料完整但来源待补充的赛事 | 边界 | 只作目录候选，不评分、不能新建项目 |
| TC-04 | 未知学历值 | 异常 | 显式拒绝，不静默改为本科生 |
| TC-05 | 推荐级关键字段证据 | 正常 | 五类字段具备原文/URL/获取与检查日期；PDF 有页码，HTML 可无页码 |
| TC-09 | 重复加入同一赛事 | 边界 | 幂等返回同一项目 |
| TC-11 | 加入已截止赛事 | 异常 | 拒绝创建项目 |
| TC-16 | 跨用户删除项目 | 安全 | 返回权限拒绝 |
| TC-17 | ICS 导出 | 正常 | 生成有效 VCALENDAR 且包含官方日期 |
| TC-26 | 管理接口缺令牌 | 安全 | 返回 401 |
| TC-27 | 服务端未配置管理员令牌 | 安全 | 管理写接口关闭并返回 503 |
| TC-32 | 组合方案原子采用 | 边界 | 任一赛事失效时整组不写入；重复采用幂等 |
| TC-33 | 官网关键日期变化 | 异常 | 只产生待审核事件，不自动覆盖赛事事实 |
| TC-35 | 雷达访问本机/内网地址 | 安全 | SSRF 防护拒绝非公开 HTTP(S) 目标 |
| TC-44 | LLM 润色失败 | 异常 | 引用标记丢失、HTTP 错误或无密钥时回退确定性原稿 |

执行命令：

```powershell
.\venv\Scripts\python.exe -m pytest tests -q
.\venv\Scripts\python.exe evals\run_formal_evaluation.py
```

本版实测：自动回归 **152/152 通过**（26 项子测试），正式量化评测 **15/15 通过**，全量自动模板问答 **786/786 通过**；2026-10-04 干净仓库检出复测同样通过 152 项回归及 26 项子测试。模板集不是人工金标。完整用例与实测报告见 [../docs/TEST_CASES.md](../docs/TEST_CASES.md)、[../docs/QUANTITATIVE_EVALUATION.md](../docs/QUANTITATIVE_EVALUATION.md) 和 [../evals/report.md](../evals/report.md)。
