## 🧪 执行方式

```powershell
.\venv\Scripts\python.exe -m unittest discover -s tests -v
```

## 📋 用例明细

| ID | 场景 | 类型 | 预期结果 |
| --- | --- | --- | --- |
| TC-01 | Ground Truth 日期与 SQLite 比对 | 正常 | 21 项报名/提交日期完全一致 |
| TC-02 | 已截止赛事推荐（含仅有提交截止） | 边界 | `ineligible` 且 `score=null` |
| TC-03 | 未核验赛事推荐 | 异常 | `candidate_only` 且不评分 |
| TC-04 | 未知学历值入库 | 异常 | 显式失败，不转为本科生 |
| TC-05 | 十二项已核验赛事证据完整性 | 正常 | 核心字段均有页码、原文、URL 和日期 |
| TC-06 | RAG 与 Agent 截止日期 | 正常 | 只输出一个规范截止日期 |
| TC-07 | 无全国统一报名日 | 边界 | 明确回答未给出，不编造日期 |
| TC-08 | 加入已核验且开放赛事 | 正常 | 创建项目和默认任务/材料 |
| TC-09 | 重复加入同一赛事 | 边界 | 幂等返回同一项目 |
| TC-10 | 加入未核验赛事 | 异常 | 返回拒绝 |
| TC-11 | 加入已截止赛事（报名日缺失时检查提交日） | 异常 | 返回拒绝 |
| TC-12 | 项目截止日期读取 | 正常 | 与赛事主表实时一致 |
| TC-13 | 更新项目状态 | 正常 | 状态持久化为进行中 |
| TC-14 | 完成任务条目 | 正常 | 条目状态变为完成 |
| TC-15 | 新增并删除材料 | 正常 | 材料正确创建和删除 |
| TC-16 | 跨用户删除项目 | 异常 | 所有权校验拒绝删除 |
| TC-17 | ICS 导出 | 正常 | 包含有效 VCALENDAR 和官方日期 |
| TC-18 | 删除画像 | 正常 | 画像、项目和条目级联删除 |
| TC-19 | 同名赛事存在已核验版本 | 边界 | 明示使用最新已核验年份 |
| TC-20 | 同名赛事均未核验 | 边界 | 追问具体年份 |
| TC-21 | 用户明确年份 | 正常 | 锁定对应年份版本 |
| TC-22 | 查询不存在项目 | 异常 | 返回空或 404 |
| TC-23 | 无自定义任务的 ICS | 边界 | 日历结构仍然有效 |
