# V0.5 参赛候选版冻结说明

> 更新日期：2026-08-10。本文描述最终提交前的冻结门槛；只有全部门槛通过后才生成候选归档包。

## 冻结范围

- `src/`：FastAPI、数据访问、推荐、Agent、雷达与检索代码。
- `frontend/`：当前用户端单页应用。
- `data/ground_truth/`：179条原始样本及其纠名、归档清单；运行时 SQLite 数据库不作为源代码提交依据。
- `docs/`、`submission/`、`evals/`、`tests/`、部署配置和单独上传的正式 MP4 演示视频。

冻结包不包含本地虚拟环境、`.env`、运行期数据库、浏览器缓存、临时文件及设计过程截图。归档包生成后应同时输出 SHA-256 文件。

## 冻结门槛

1. 正式评测15/15、自动回归59/59、Python编译和JavaScript语法检查全部通过。
2. README、参赛说明、架构、合规、测试用例与演示脚本的数据口径一致。
3. 核心演示赛事的来源雷达无未解释失败；待审核变化已分类处理。非核心来源若暂不可访问，必须保留真实 `stale` 状态、失败原因和人工复核提示，不能伪装为正常。
4. 首页、赛事大厅、推荐、项目、机会提醒和智能顾问在桌面端与移动端无白底残留、文字遮挡或横向溢出。
5. 正式模式不暴露本地管理员快捷登录入口；管理员写接口仍要求独立令牌。
6. Docker 启动、`/health`、离线知识库回退和关键安全场景均已复验。

## 生成与核验

冻结完成后在发布环境生成归档包，并执行：

```powershell
.\venv\Scripts\python.exe scripts\create_release_bundle.py
Get-FileHash -Algorithm SHA256 backups\campus-innovation-agent-v0.5-*.zip
```

该脚本只纳入源码、文档、测试、Ground Truth、部署文件和提交索引，自动排除本地虚拟环境、运行数据库、`.env`、缓存、设计过程截图和演示视频；正式 MP4 应按平台要求单独上传。归档旁应保存：SHA-256、正式评测 JSON、量化报告、端到端验收记录和录制日期。任何数据、依赖或界面改动后，都必须重新执行全套门槛，不能沿用旧报告。
