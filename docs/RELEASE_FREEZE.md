# v1.3 交付冻结规则

当前事实、评测与视频以 [提交快照](SUBMISSION_STATUS.md) 为准。归档由 `scripts/create_release_bundle.py` 从当前文件生成，并附 SHA256 清单。旧 v1.2 包保留为历史版本，不应作为本版提交包。

归档排除私密 `.env`、运行数据库、上传数据、缓存、旧视频和其他 ZIP；仅保留正式演示视频与公开官方资料。打包前执行凭据模式扫描。保存字段证据与官方快照，不改变截止日期，不补造缺失规则。

本版没有部署或推送承诺。生产启动验证属于代码防护，无法替代服务商端密钥轮换。提交前须验证旧数据库凭据与模型密钥失效，当前仍未验证。真实用户试用及在线规划模型效果单独待验收。
