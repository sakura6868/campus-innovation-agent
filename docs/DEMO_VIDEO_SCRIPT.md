# 3—5 分钟演示视频脚本

已录制文件：[`demo/campus-agent-demo.webm`](../demo/campus-agent-demo.webm)，时长 4 分 59 秒，无旁白版本。

_建议成片 4 分钟，1920×1080，浏览器缩放 100%。_

---

## 🎬 分镜与讲解

| 时间 | 画面操作 | 讲解重点 |
| --- | --- | --- |
| 00:00–00:20 | 打开首页，选择“综合型”身份 | 目标用户是在校生，解决赛事信息分散和规则冲突 |
| 00:20–00:50 | 打开赛事大厅，切换“可正式推荐 / 待核验候选”，进入中国软件杯 | 展示官网来源确认状态、唯一截止日期、页级官方证据 |
| 00:50–01:20 | 在详情页检索“报名截止”，点击引用 | RAG 强制赛事与年份隔离，回答可追溯到 PDF 第 2 页 |
| 01:20–01:45 | Agent 询问“中国软件杯报名截止” | 展示唯一规范日期与引用，强调不会产生两个截止日 |
| 01:45–02:05 | Agent 询问“蓝桥杯报名截止” | 展示同名多年份追问；再输入“2026年蓝桥杯”完成锁定 |
| 02:05–02:30 | 打开我的推荐 | 该页面只显示官网来源与关键证据完整、仍可报名且资格通过的赛事；候选只在大厅展示 |
| 02:30–03:10 | 加入中国软件杯，进入我的项目 | 展示自动任务、材料清单、完成状态和官方截止日期 |
| 03:10–03:30 | 勾选任务、新增材料、切换项目状态 | 展示项目规划闭环 |
| 03:30–03:45 | 点击导出 ICS | 展示日历文件由赛事主表日期生成 |
| 03:45–04:05 | 输入演示管理员令牌，上传一份官方 PDF 并解析 | 展示受保护的数据维护、页码解析、证据关联和自动完整性分类 |
| 04:05–04:20 | 打开画像删除按钮但取消 | 说明数据最小化、用户可删除、演示不使用真实敏感信息 |

## ✅ 录制前检查

- 服务地址使用 `http://127.0.0.1:8000/`
- 浏览器无个人书签、账号头像或通知弹窗
- 预先删除演示用户已有项目，保证加入流程清晰
- 官方 PDF 链接可访问；网络不稳定时使用本地页级证据弹窗
- 终端预先运行 36 条回归测试和 15 条正式指标用例并保留通过结果备用
- 成片控制在 3—5 分钟，字幕与讲解中的日期必须和页面一致
