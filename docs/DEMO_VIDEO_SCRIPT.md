# V0.5 · 4–5 分钟评审演示脚本

> 录制前先执行正式评测和自动回归；录制使用本地服务与演示账号，不展示管理员令牌、密码或数据库文件。

## 演示准备

1. 启动服务后确认 `GET /health` 返回 `status: ok`。
2. 预先准备一个已保存画像的演示账号，并保留一个空项目状态用于展示创建闭环。
3. 确认赛事大厅、机会提醒和智能顾问均可打开；网络不可用时演示本地知识库回退即可，不强制依赖外网。
4. 录制前运行 `python evals/run_formal_evaluation.py`，确保 15/15 正式指标和 59/59 自动回归通过。

## 现场兜底话术

- 网络不可用： “联网补充是可选增强；当前已自动回退到本地赛事证据链，核心推荐、项目与规则问答仍可运行。”
- 某赛事来源待补充： “该条以基础资料提供导航和匹配，页面明确标注来源状态；正式报名以官网最新通知为准。”
- 雷达发现变化： “变化先进入待审核事项，未确认前系统继续使用最后可信版本。”
- 评委询问数据范围： “当前共有179条年度化赛事记录，146条前台展示，33条归档保留审计，16条达到A级证据标准。”
