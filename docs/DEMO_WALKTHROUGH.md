## 已验证主流程

| 步骤 | 实测结果 |
| --- | --- |
| 注册与登录 | 临时账号注册后获得签名会话，成功进入画像页。 |
| 隐私授权 | 授权弹窗明确告知最小化采集范围；同意后才允许保存画像。 |
| 保存画像 | 填写本科生、软件工程、Python/前端/算法、可用时间和队伍人数后成功保存。 |
| 个性化首页 | 展示今日焦点、匹配赛事、官方变化和项目入口。 |
| 赛事大厅 | 146条展示赛事可按正式名称、类别、年份和报名状态查找。 |
| 推荐与项目 | 推荐页给出匹配理由；加入赛事后成功创建七阶段任务与材料模板。 |
| 项目四视图 | 列表、看板、日历、时间线均能切换；依赖任务会显示阻塞关系。 |
| 机会提醒 | 展示优先处理事项、当前机会和已加入项目的提醒入口。 |
| 智能顾问 | “推荐三场值得投入的比赛”返回三场赛事、匹配度、能力缺口、取舍说明和可展开的回答依据。 |
| 正式登录页 | 不展示本地管理员快捷登录入口；管理员写接口仍保持独立令牌保护。 |
| 主题与响应式 | 项目空状态、机会组合与授权弹窗均为深色圆角拟态材质；桌面端和 390px 移动端均无横向溢出或白底残留。 |

## 稳定性与安全复验

| 场景 | 结果 |
| --- | --- |
| `/health` | 返回200，数据库状态为 connected，未泄露连接地址或密钥。 |
| 未登录读取用户画像 | 返回401。 |
| 跨用户资源访问 | 自动回归验证返回403。 |
| 未配置管理员令牌的写接口 | 返回503并保持关闭。 |
| 本地管理员快捷接口未启用 | 返回404。 |
| 外部来源指向本机、内网或非HTTP(S) | SSRF 自动回归验证拒绝请求。 |
| 外网或LLM不可用 | 回退本地赛事知识库，核心推荐和规则回答不中断。 |
