# 校园科创导航智能体 · V0.5 创新点单页

## 一句话定位

面向在校生的赛事行动智能体：把“找赛事”升级为“基于来源状态作出选择、接收变化、生成计划并推进参赛项目”的可解释闭环。

## 五个可现场验证的创新点

### 1. 年份化赛事事实与纠名归档

每条赛事以 `competition_id + 年份 + 文档版本` 管理。原始采集样本与纠名、归档清单分离保存：发现名称错误、旧赛季或无可靠来源时不删除痕迹，而是归档并保留审核理由。当前179条记录中，146条面向用户展示、33条归档保留审计。

**评审价值：** 不把“搜索到的名称”直接当作可信赛事，数据更适合持续维护和复用。

### 2. 双层赛事雷达 + 人工审核门

可行动赛事高频关注报名、提交等关键变化；已结束或执行中赛事低频追踪下一赛季公告和结果。网页、PDF、DOCX统一生成快照与差异，但所有变化先进入审核队列，未确认前保留最后可信版本。

**评审价值：** 既能发现变化，也能避免抓取噪声直接污染推荐与项目任务。

### 3. 从单场排序到三路线机会组合

系统综合学历、年级、技能、队伍人数、每周可投入时间、截止冲突与已有项目，输出稳妥、均衡、冲刺三条路线。采用组合时会重新校验，任一赛事失效即整组回滚。

**评审价值：** 给学生的是可执行的选择策略，而不是一串没有取舍说明的赛事列表。

### 4. 七阶段项目执行闭环

加入赛事后自动生成“资格核对、组队选题、报名、方案、制作、提交、答辩”任务链。任务支持依赖、阻塞原因、材料管理和 ICS 导出，并提供列表、看板、日历、时间线四种视图。

**评审价值：** 打通“推荐—行动—推进—复盘”，能直接对应工程导向评审的任务闭环要求。

### 5. 可解释、可降级的智能顾问

问答由赛事识别、年份消歧、隔离检索、事实门控和表达层组成。回答给出来源、能力缺口和取舍；网络或可选 LLM 不可用时，4秒内回退到本地知识库，不用模型常识补造规则。

**评审价值：** 现场网络不稳定时核心能力仍可演示，且回答边界清晰、来源可追溯。
