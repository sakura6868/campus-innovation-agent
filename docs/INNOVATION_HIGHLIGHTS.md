# 校园科创导航智能体 · 创新点单页

> 参赛类别：校内 Agent 比赛　|　更新：2026-07-21　|　仓库：`campus-innovation-agent`

---

## 🎯 一句话定位

不是又一个「问答机器人」，而是一条**不编造的可信赛事数据闭环**——每条信息可溯源、每场推荐可门控、每次作答带官方证据。

学生面对海量赛事时，普遍卡在三件事上：**真假难辨**（网上抄来的截止日期常错）、**错过报名**（推荐里混着早已截止的赛事）、**硬条件不符仍被推荐**（研究生被推只收本科生的比赛）。本作品用一条**反幻觉红线**把这三件事一次性解决。

---

## 💡 五大核心创新

### ① 不编造的可信赛事库（最硬底线）
- **做法**：每条赛事带 `official_source_status`（`found` / `not_found`）。确无官方出处时，**清空证据、保留原始字段、加红字提示**，绝不自动补全日期 / 主办 / 奖项。
- **价值**：把幻觉从源头掐断，直击「网传信息常错」的普遍痛点。
- **难点**：依赖一套确定性来源 + 证据校验规则（`src/trust.py`），而非靠 LLM 现场生成。

### ② 证据一致问答（可溯源 + 千问润色隔离）
- **做法**：每条结论挂接「文档·页码·原文·官方链接」四要素，前端渲染为可点击 `[n]` 角标并平滑滚动到依据卡。配置千问 key 后，`qwen-plus` **仅润色自然语言层**，`[n]` 与门控结论保持确定性不变。
- **价值**：用户一键跳到官方依据，可信度可验证；润色不污染证据。
- **难点**：引用生成与 LLM 润色**解耦**，避免模型改写破坏溯源。

### ③ 赛事隔离 RAG（杜绝跨赛事串味）
- **做法**：检索按 `competition_id` + 年份 + 版本**三重隔离**；未装向量库时自动降级为本地字段 / 原文匹配，离线可跑、结果可控。
- **价值**：避免「问 A 赛答 B 赛证据」的串味幻觉；部署零额外依赖。
- **难点**：隔离索引 + 优雅降级两条路径都要保正确。

### ④ 画像驱动推荐 + 时间门控「只推报名中」
- **做法**：按学生画像（专业 / 年级 / 学历）软匹配 + 硬资格门控；**已截止或硬条件不符的赛事一律 `score=null` 剔除**。同一账号切换「计算机 / 工商管理 / 设计 / 文科」画像，推荐列表明显分化。
- **价值**：同时解决「错过报名」与「硬条件不符仍被推荐」，做到千人千面。
- **难点**：门控与评分分离，截止即剔除，不进软评分。

### ⑤ 免 key 联网补充层（反幻觉隔离）
- **做法**：本地证据不足（最新动态 / 报名通知 / 官网更新）时，调用 **DuckDuckGo 即时检索（无需任何 API key）**，结果以独立「🌐 联网信息（仅供参考，以官网为准）」卡片呈现，**绝不混入本地 `[n]` 引用**。
- **价值**：补足时效性又不破坏可溯源红线；零配置即联网，部署到公网即生效。
- **难点**：联网结果与本地证据**严格分域**，互不串用。

## 🆚 与通用方案的本质区别

| 维度 | 通用 AI 助手 | 本智能体 |
|------|------|------|
| 截止日期来源 | LLM 记忆 / 易编造 | Ground Truth 原样入库，不做平移改写 |
| 无官方来源时 | 可能瞎编 | 标 `not_found` + 红字提示 |
| 推荐是否含已截止赛事 | 经常含 | `score=null` 剔除 |
| 答案可溯源 | 多数不能 | 每条带 `[n]` 官方依据角标 |
| 联网与本地证据 | 混在一起 | 严格分域隔离 |
| 无 LLM / 无网络时 | 直接不可用 | 确定性模板仍可跑，结果可复现 |
